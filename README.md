# AeroFlow

> Your specs take flight.

AeroFlow is a guided AI workflow manager for developers.

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Tech Stack

- [Next.js 15](https://nextjs.org) (App Router, Turbopack)
- TypeScript
- Tailwind CSS v4
